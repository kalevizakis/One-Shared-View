## How to Use This Index

**When creating a note:**
1. Add a row to the table above
2. Keep "Purpose" to 5-10 words max

**When deleting a note:**
1. Remove the row from this table
2. Remove the reference from the linked memory file
3. Delete the note file

**Checking for cleanup:**
- Review "Delete When" conditions periodically
- If condition is met → delete the note
