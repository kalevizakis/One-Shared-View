What ESSENCE is

One LLM. A governed ten-persona dev team that verifies itself.

ESSENCE is a behavioral contract written as text — 8 guards, 12 rules, 10 personas — that routes every request through safety gates and specialist roles. Its core trick: simple work stays on a lean ~4K-token core, while risky or complex work automatically loads the full 5K-token rule playbook. Cheap when simple. Rigorous when it matters.

The foundation: it verifies itself

Everything above stands on tooling that keeps the contract honest — at authoring time and at run time.

Drift lint
tools/drift_lint.py · ~80 checks · exit 1 on drift
Every count, version stamp, link, and the lean/load contract itself is machine-verified against the single source of truth. A file that disagrees fails the build.
Measured claims
evals/measure-tokens.py · ±15% tolerance
The token budgets printed in the docs are re-measured from the shipped files on every run. Efficacy numbers can never quietly rot into fiction again.
Live telemetry
VS Code OTLP → PostgreSQL → dashboard
A Docker pipeline records every span and prices every session in Copilot credits — per model, per workspace — so the cost of the contract is observable, not assumed.
